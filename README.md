
# Java Employee Payroll Model

A Java application I developed for CSC 223 at Northern Virginia Community College. The program calculates and displays employee pay based on different compensation structures for full-time and part-time workers.

## Features

- Calculate pay for full-time and part-time employees
- Apply salary and bonus amounts for full-time employees
- Calculate part-time earnings using hours worked and hourly rates
- Display employee IDs, names, and calculated pay
- Use inheritance and polymorphism to manage different employee types

## Technologies Used

- Java
- Object-Oriented Programming
- Inheritance and Polymorphism
- Eclipse IDE

## How to Run

1. Download the repository.
2. Open Eclipse and create a Java project.
3. Copy the files from `src/Module1` into a package named `Module1`.
4. Run `EmployeeTestDrive.java` as a Java Application.
5. View the employee information and calculated pay in the Console.

## Testing

I ran the application using four sample employees with different pay structures. The program calculated and displayed the expected amounts for both full-time and part-time employees.

## Project Background

I developed this project to strengthen my understanding of Java inheritance and polymorphism while applying those concepts to a basic employee payroll system.
